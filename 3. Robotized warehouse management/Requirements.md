### Functional Requirements
- **Robot Fleet Management:** the system should operate the team of robots, communicate with robots interface to delegate tasks to them
- **Inventory Tracking:** the system should keep track of the inventory and provide staff with all the information
- **Scheduled tasks:** the system should handled scheduled tasks
- **Event based tasks:** the system should handled event based tasks, monitor events' input sources
- **Manual tasks:** the system should handled tasks submitted manually by staff members
- **API:** the system should have an API
### Non-functional Requirements
- **Scalability:** the system should support scaling the warehouse and number of robots
- **Safety:** the system should consider all the risk factors and prevent failures
- **Efficiency:** the system should manage the tasks to be performed in the most efficient way
- **Security:** the system should prevent unauthorised access to its components
