# Chess simulation requirements
### Functional Requirements
- **Starting a game:** user should be able to start a game
- **Seeing the table:** user should be able to see the chess table with current position and coordinates
- **Making a move:** user should be able to make one move per turn
- **Finishing the game:** user should be able to finish the started game
- **Rule Enforcement:** the system should enforce the official rules of chess

### Non-functional Requirements
- **Scalability:** The system must support up to 10,000 concurrent users
- **Reliability and Availability**: The system should have 99.9% uptime
