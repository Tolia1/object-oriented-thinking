### Functional Requirements
- **Physical Copying:** user should be able to create a copy of existing physical document
- **Printing from USB:** user should be able to print a digital document provided on a USB device
- **Printing via Email:** user should be able to print a digital document sent to the specified email address
### Non-functional Requirements
- **Speed:** the printer should be able to print at least 7 pages per minute
- **Color:** the printer should support colored printing
- **Security:** only university students and staff members should have access to the device
